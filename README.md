# PropFirm 工作室管理系统
统计各Propfirm出金情况，支出成本，出金账户数量、Live出金情况、多身份信息统计

## 功能特点
- 👥 动态人员管理（无限添加/删除）
- 🏷️ PropFirm平台库（英文大写、增删功能）
- 💰 资助账户 / 🔥 Live账户 / 📚 考试账户 分类管理
- 📊 同平台分组排序展示
- 💵 四步出金记录（交易员 → 资助账户 → 金额 → 日期）
- 📈 自动汇总统计（按平台、按Live、按人员）

## 数据说明
- 所有数据保存在浏览器的本地存储中
- 清除浏览器缓存会导致数据丢失
- 建议定期导出备份
